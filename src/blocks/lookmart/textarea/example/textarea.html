Подключение

Стили и JavaScript компонента подключаются отдельно:

import '@apress/apress-ui/dist/lookmart/textarea.css';
import '@apress/apress-ui/dist/lookmart/textarea.js';

Изменение высоты при наборе текста

Для автоматического изменения высоты textarea нужен класс js-autogrow-textarea. Поле будет растягиваться при вводе, в том числе если оно было добавлено в DOM динамически.

Если динамически добавленное поле уже содержит текст, после вставки нужно вызвать событие инициализации на самом textarea или на его контейнере: 

container.dispatchEvent(
  new Event('init:textarea', { bubbles: true })
);

Если жизненным циклом поля управляет сама форма, функции изменения высоты можно импортировать без автоматической установки обработчиков: 

import {
  handleTextareaResize,
  initTextareas,
  resizeTextarea
} from '@apress/apress-ui/src/blocks/lookmart/textarea/textarea-resize';

Плавающий плейсхолдер

Для работы плавающей подписи в placeholder обязательно должен быть задан пробел (placeholder=" ").

Счетчик символов

Если у поля задан maxlength и внутри блока есть элемент js-aui-textarea-counter, счетчик показывает, сколько символов осталось. Он обновляется при вводе и при событии init:textarea.
